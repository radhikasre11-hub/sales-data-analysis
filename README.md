# Sales Data Analysis 📊

## Project Overview

This project focuses on analyzing sales data using Python to identify sales patterns, product performance, and regional trends. It is completed as part of the Data Analyst Internship at Cognetix Global Technology.

## Objectives

* Load and understand the sales dataset.
* Clean the data and handle missing or duplicate records.
* Calculate important sales metrics.
* Analyze product and regional sales performance.
* Create visualizations to communicate findings.
* Generate actionable business insights.

## Tools and Technologies

* **Python** — programming and analysis
* **Pandas** — data manipulation and analysis
* **NumPy** — numerical operations
* **Matplotlib** — data visualization
* **Seaborn** — statistical visualization
* **Jupyter Notebook / VS Code** — development environment

## Dataset

The project uses the Sample Sales Data dataset from Kaggle.

Dataset link: https://www.kaggle.com/datasets/kyanyoga/sample-sales-data

## Project Workflow

### 1. Data Loading

Imported the required Python libraries and loaded the CSV dataset using Pandas.

### 2. Data Exploration

* Viewed the first few records.
* Examined column names and data types.
* Generated descriptive statistics.

### 3. Data Cleaning

* Checked for missing values.
* Identified and removed duplicate records where appropriate.
* Converted the order date column into a datetime format.

### 4. Sales Analysis

* Calculated total, average, maximum, and minimum sales.
* Analyzed sales by product line.
* Compared sales across territories.
* Examined monthly sales trends.
* Identified top-performing products and countries.

### 5. Data Visualization

The project includes the following charts:

1. Sales by product category (product line)
2. Sales by region (territory)
3. Monthly sales trend
4. Top 10 products by sales
5. Sales distribution by deal size
6. Top 10 countries by sales

## Key Insights

The analysis is used to identify:

* The highest-performing product line.
* The territory contributing the most sales.
* Monthly changes in sales performance.
* The products and countries generating the highest sales.
* The distribution of sales across deal sizes.
* The product line with the highest total sales was [Classic Cars].
* The territory with the highest sales was [APAC].
* Sales reached their peak in [November 2004].

## Conclusion

This project demonstrates how Python libraries can be used to clean, analyze, and visualize sales data. The results can help businesses understand sales performance, identify strong-performing products and markets, and make data-driven decisions.

## How to Run the Project

1. Install Python.

2. Install the required libraries:

   `pip install pandas numpy matplotlib seaborn jupyter`

3. Keep the CSV dataset and `analysis.ipynb` in the same project folder.

4. Open the notebook in VS Code or Jupyter Notebook.

5. Run the notebook cells in order.
